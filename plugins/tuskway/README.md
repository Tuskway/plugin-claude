# Tuskway

Tuskway is a shared epic notebook for software teams. Each epic keeps its notes, a sectioned tech design, and ticket briefs in one place, so every coding agent on the team works from the same plan.

This plugin bundles two things: the hosted Tuskway MCP server at `https://tuskway.com/mcp`, and workflow skills in `skills/` for starting an epic, writing the design, drafting tickets, planning parallel work, tackling a ticket, and handling comments and tracker changes.

To start, add the plugin to your client and sign in to Tuskway with OAuth when the client asks. Then ask your agent to list your epics or run one of the skills.

The package stores no access tokens. Per-client install steps are in the repository README.
