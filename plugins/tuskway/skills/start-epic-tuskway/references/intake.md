# Intake note

Keep headings that are already in `notes.md`. Add only the blocks you can fill.

```markdown
# <epic title>

## Problem

What is wrong or missing.

## Desired outcome

What will be true when this is done.

## Constraints

Facts that limit the solution.

## Non-goals

Work this epic will not do.

## Delivery repo

The repo path you checked, or "unknown" if you could not open it.

## Decisions

- D1: <decision the user already made>

## Open questions

- <question whose answer changes the design>
```

When you update an existing note, leave decisions you were not asked to change. A new question goes under Open questions. It does not delete an older decision.
